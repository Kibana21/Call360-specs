# Stage acceptance evidence

This directory is the authoritative record of stage results across the **three** Call360 repos. Create `S0.md` from `S0_TEMPLATE.md` and use a similar structure for `S1.md`–`S6.md`. A template is not an acceptance statement.

Each acceptance record must state: owner approval, date, linked requirement IDs, implementation scope, architecture/contract changes, exact specs/backend/frontend commits, OpenAPI SHA-256, database migration revision, environment, test commands, CI/E2E output references, unresolved defects and explicit go/no-go. Do not mark a gate PASS merely because UI screenshots were produced.
